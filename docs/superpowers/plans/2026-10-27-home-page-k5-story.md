# Home Page with the K5 Scroll Story — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the Nuxt 3 public site skeleton (layout, i18n, tokens, API client) and build the new home page whose hero is a pinned, scroll-driven scene in which the K5 turbine is manufactured, assembled and installed.

**Architecture:** Nuxt 3 (SSR) app in `frontend/`. The story is one inline SVG whose geometry is generated by pure TypeScript functions (rendered on the server too, so the page is never blank), animated on the client by a GSAP ScrollTrigger timeline that pins the section and scrubs a single timeline; the camera is the SVG `viewBox`. Everything below the story is ordinary sections fed by the .NET public API (`/api/*`) through one small fetch composable.

**Tech Stack:** Nuxt 3.21, Vue 3.5, @nuxtjs/i18n 9 (uk default without prefix, en under `/en`), @nuxtjs/tailwindcss 6, @nuxtjs/sitemap 7, @pinia/nuxt (installed, unused here), gsap 3.12, @fontsource-variable/commissioner, vitest (geometry tests only).

**Spec:**
- `docs/prototypes/k5-scroll.html` — the approved throwaway prototype: scene geometry, stage timings, camera viewBoxes, copy (uk), palette. The real build ports it, it does not link to it.
- `docs/PLAN.md` — the site-wide migration plan (Nuxt page list, API contract, env contract, SEO rules).
- Decisions from the brainstorm: light theme only; brand green `#576e4f`; engineering/reliable voice; anti-references = template landing (identical icon cards, gradients, stock smiles), "eco" clichés (leaves, lime green), overloaded shop (discount banners, timers, popups), dark theme. Below the story: products, why vertical, projects, blog, contacts — big photos, numbers, text, no twin cards.

## Global Constraints

- Runtime env contract (from `docs/PLAN.md` / compose): `NUXT_API_BASE` = API origin for SSR (dev `http://localhost:5000`, prod `http://api:8080`); `NUXT_PUBLIC_API_BASE` = origin for the browser (`""` = same origin, nginx proxies `/api/`); `NUXT_PUBLIC_SITE_URL` (`https://uagreen.co`); `NITRO_PORT=3000`.
- API paths are always `${base}/api/...`; every public GET takes `?lang=uk|en`; EN falls back to UK inside the API.
- Media URLs come from the API already prefixed (`/media/<key>`); never build them in the frontend.
- Locales: `uk` default, no prefix; `en` under `/en`; `detectBrowserLanguage: false`; no `ru`.
- Palette (prototype `:root`): `--bg #f6f7f5`, `--ink #1f2a22`, `--ink-2 #44524a`, `--green #576e4f`, `--green-2 #3f5239`, `--copper #b5673a`, `--line #d8ddd6`, `--metal #8a948c`, `--metal-2 #c3c9c1`, `--concrete #cfd2cb`, `--soil #e6e8e3`. Light theme only; no `prefers-color-scheme: dark` branch.
- Contrast: body text ≥ 4.5:1 (`--ink` and `--ink-2` on `--bg` both pass; `--green` on `--bg` = 5.2:1 is the floor for green text). Body line length ≤ 70ch. Display headings `clamp()` max ≤ 4rem, letter-spacing ≥ −0.02em, `text-wrap: balance`.
- Font: `Commissioner Variable` (self-hosted via fontsource; Ukrainian-designed, Cyrillic-first). `font-family: 'Commissioner Variable', system-ui, sans-serif`. Swap to e-Ukraine only when the owner supplies the files.
- Motion: ease-out curves only (`power2.out/inOut`), no bounce. `prefers-reduced-motion: reduce` (and `?motion=off`) ⇒ no pin, finished scene, all steps stacked. Content is visible before any animation runs (SSR renders the full SVG + first step).
- Banned patterns (impeccable): side-stripe borders, gradient text, glassmorphism, hero-metric template, identical card grids, uppercase tracked eyebrow above every section, numbered section markers by reflex (the five story stages are a real sequence and may be numbered on the rail only), text overflowing at 375px.
- Every dynamic section must degrade: API unreachable at SSR ⇒ page still 200 with header, story and static sections; the section whose data failed renders nothing (no spinner, no error box).
- Commit after each task with the trailer `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Do not commit `frontend/node_modules`, `.nuxt`, `.output`.

## Review Focus

1. API down or slow at SSR time → `GET /` still 200 with `<h1>` and the SVG; no unhandled promise in the server log. (Test in Task 4, step 6.)
2. `/en` with partial EN content → English UI strings everywhere, API-fallback UK bodies allowed, `<html lang="en">`, hreflang pair present. (Test in Task 5, step 4.)
3. Reduced motion / `?motion=off` → no pinned 7000px section; the finished turbine and all five steps are visible without scrolling tricks. (Test in Task 3, step 7.)
4. 375px viewport → story headline and step copy fit without horizontal scroll; SVG stays visible above the copy. (Test in Task 3, step 8.)
5. Hydration: SVG geometry generated on server and client must be byte-identical (fixed decimals, phase 0 at SSR) → no `Hydration` warnings in the browser console. (Test in Task 3, step 6.)

### Task 2: K5 scene geometry (pure TS) + tests

**Files:**
- Create: `frontend/components/story/scene.ts`, `frontend/components/story/scene.test.ts`, `frontend/vitest.config.ts` (`test: { include: ['components/**/*.test.ts'] }`, no Nuxt environment)

**Interfaces:**
- Constants exported: `RX = 140, RY = 70, N = 72, LAMS = 20, TOPY = -4 * (LAMS - 1), DR = 0.66, H = -TOPY, ROW = H / 3, HOVER = TOPY - 130, R = 125, TOP = -320, BOT = -80`.
- `pt(r: number, a: number): string` → `"x,y"` with one decimal, `x = RX·r·cos a`, `y = RY·r·sin a`.
- `ring(r0: number, r1?: number): string` closed ellipse path(s).
- `lamPath(): string` — outer rim with 4 lugs at 45/135/225/315° (radius 1 → 1.06, notch 1.03) + 72 slots open to the bore: `rin 0.72, rslot 0.9, half 0.22·pitch, open 0.15·pitch`, rounded bottom (3 arc points), `fill-rule: evenodd`.
- `bandPath(): string` — front half of the drum side: top arc r=DR, down H, back along the bottom arc.
- `bandClipPath(): string` — region above the stack top plane bounded by the front arc of the bore ellipse at `y = TOPY + RY·DR·sin a`.
- `magnets(): { x: number; y: number; w: number; h: number }[]` — 3 rows × 24 angles, only `sin a ≥ 0.1` (36 visible), `w = 3 + 11·sin a`, `h = ROW − 4`.
- `coilPath(i: number): string` for `i in 0..35`: `a = i·2·pitch + pitch/2`, `b = a + 4·pitch`, `M pt(0.74,a) L pt(0.88,a) Q pt(0.96,a+pitch) pt(0.96,(a+b)/2) Q pt(0.96,b−pitch) pt(0.88,b) L pt(0.74,b)`.
- `flangeWindows(): string[]` — 3 arcs at r=0.45 from 15° to 75° offset by 0/120/240.
- `housing(): { side: string; lid: string; studs: { x: number; y: number }[]; cable: string }` — the finished generator from the owner's photo: steel drum `HR = 1.14` from `y = 56` (bottom, below the stack) to `TOPY − 8` (top, front half), lid = `ring(HR)` at `TOPY − 8`, 4 hex nuts on studs at r=0.98 / 45°+k·90° (hex 7×3.5 top face, 6px body, 5×10 stud with an elliptical cap). No cable. Shaft 40 wide (x −20..20, y −200..−2) with an elliptical cap rx 20 ry 10, drawn in its own group above the lid; the assembly shaft is 14 wide. Fades in (opacity), not dash-drawn.
- `rawBlade(x: number, k: 0..4): string` — lens at `cy=1280`, `w = 13·(1 − k·0.18)`, `h = 240·(1 − k·0.07)` (k=0 is the outer).
- `bladePath(i: 0|1|2, phaseDeg: number): string` — 15 points, `a = phase + i·120 + k/14·120`, `x = R·cos a`, `y = TOP + (BOT − TOP)·k/14`.
- `strutPaths(phaseDeg: number): { top: string; bot: string; topLen: number; botLen: number }[]` (3 entries).
- `ladderPath(): string` — `M918,1400V510M930,1400V510` + rungs every 28 from 1390 down to >510.
- Camera: `CAM = { title: '0 0 1400 1556', gen: '165 990 370 411', blades: '60 1040 400 444', asm: '100 1000 500 556', mast: '300 300 1100 1222', install: '250 160 1150 1278', end: '450 60 900 1000' }`.

import { describe, it, expect } from 'vitest'

    expect(magnets().length).toBe(36)
